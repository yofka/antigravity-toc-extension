# Antigravity Chat TOC Navigator (Chrome Extension)

Google Antigravity のチャット画面に見出し目次ナビゲーションを表示する Chrome 拡張機能です。

## 主な機能

- **チャット目次ツリー**: プロンプト（質問）および AI 応答内の見出し（h1〜h6）を階層ツリーで表示・ワンクリック移動。
- **自動目次リフレッシュ（`👁`）**: **デフォルトON**。新たな質問や応答、チャットのスクロール、ナビゲーション操作時に自動で目次を追従更新。不要な再描画を防ぐフィンガープリント差分検知付き。
- **チャット操作ボタン（1段目）**:
  - `⏮`（Home） / `▲`（PageUp） / `▼`（PageDown） / `⏭`（End）: チャット画面のスクロール移動。
  - `⏫ 全履歴読込`: チャット最上部まで自動巡回し、過去の会話履歴を一括ロード。
- **ツールバー（2段目）**:
  - `▼`: ピル型ボタンへ最小化（ドラッグで自由移動可能）。
  - `⇔`: チャットペインの左右配置切替（左端 ⇔ 右端）。
  - `⟳`: 手動目次更新。
  - `👁`: 自動目次更新の On / Off 切り替え（青: ON / 灰: OFF）。
  - `📌`: チャットペイン潜り込みドッキング（サイドバーやアーティファクトと重ならず幅連動）。
  - `×`: パネルを閉じる。
- **展開深度 & 折り返し（3段目）**:
  - `深度 1〜6`: 階層ごとの一括展開・折りたたみ。
  - `Wrap`: 1行省略表示と全文折り返し表示の切り替え。
- **リサイズ**: パネル内側の境界線を左右ドラッグして幅を自由調節。
- **ショートカット**: `Alt + T` で目次の展開／最小化をトグル。

## インストール手順 (約30秒)

1. Chrome のアドレスバーに `chrome://extensions` と入力して開きます。
2. 画面右上にある **「デベロッパー モード」** のトグルスイッチを **ON** にします。
3. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
4. 以下のフォルダを選択します：
   `C:\Users\yokat\.gemini\antigravity\scratch\antigravity-toc-extension`
5. ※ 既に読み込み済みの場合は、拡張機能カード右下の **「更新（再読み込み）」アイコン（丸い矢印）** をクリックし、Antigravity 画面をリロード（F5）してください。
